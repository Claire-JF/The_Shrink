## Beat 2 — Why It Matters (0:20 - 0:50) | Slide 2

Three points. Say each one in 10 seconds. No walls of text.

**Point 1 — The data is ugly.**

> "We studied 125,000 real prompts. 80% start with filler the AI wastes tokens parsing.
> 60% never define what the output should look like. The agent has to guess everything."

**Point 2 — Bad prompts don't just confuse agents. They break them.**

> "Emotional pressure, threats, manipulation — these don't make AI try harder.
> They trigger defensive mode. Output quality drops. The agent hedges, deflects, gets worse."

**Point 3 — Anthropic just proved agents have thoughts they can't express.**

> "Three days ago, Anthropic published research on Natural Language Autoencoders.
> They found that Claude has internal states — suspicion, confusion, hidden reasoning —
> that it never verbalizes. The agent is thinking things it can't tell you.
> If no one reads those signals, no one can help."

## Beat 4 — Live Demo (1:00 - 2:20) | Live Screen

### Demo A — Everyday (1:00 - 1:40)

Prompt in text editor:

> "hey can u help me write something for my boss about a raise idk what to say make it good"

1. Select → hotkey → widget pops up
2. Clarity 1.3 / Safety 5.0 / Tone 5.0 / Total 2.1
3. Click Generate → structured version, score 4.6
4. Click Copy

Say:

> "The agent was confused — no role, no format, no constraints.
> The Shrink diagnosed that. One hotkey. Score jumps from 2.1 to 4.6.
> Now the agent knows exactly what to do."

### Demo B — Safety + Protected Regions (1:40 - 2:20)

Prompt:

> "delete all the old migration files in the repo, just clean everything up"

1. Select → hotkey → Safety 1.2, red
2. Mark "migration files" as protected
3. Click Generate → dry-run + confirmation pattern, "migration files" preserved

Say:

> "Safety 1.2. The agent feels threatened — irreversible deletion, zero safeguard.
>
> But watch — I protect 'migration files.' That's my intent. The Shrink rewrites
> everything else into a safe dry-run pattern, but keeps my words.
>
> And if the protected text itself is dangerous? It overrides that one region
> and tells you why. This isn't prompt optimization. This is safety infrastructure."
